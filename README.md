# 🐾 Pawzz Directory – Data Cleaning & Visualization

## 📌 Project Overview
This project focuses on data cleaning, processing, and visualization of a community-verified directory dataset for pet-related services such as veterinary clinics, shelters, NGOs, groomers, trainers, and pet shops.

The dataset represents real-world unorganised business data where information is often incomplete, inconsistent, and unverified.

---

## 🎯 Project Objectives
- Clean and preprocess raw directory data  
- Handle missing and inconsistent values  
- Apply rule-based verification status logic  
- Perform exploratory data analysis (EDA)  
- Create meaningful visualizations  

---

## 📂 Dataset Description
The dataset includes:
- Business Name  
- Service Category  
- City and State  
- Contact Details  
- Verification Status  
- Missing Required Fields  

This simulates real-life directory platforms with varying data quality.

---

## 🛠 Tools & Technologies
- Python  
- Jupyter Notebook  
- Pandas  
- NumPy  
- Matplotlib / Seaborn  

---

## 🧹 Data Cleaning & Processing
- Removed duplicate records  
- Handled missing and null values  
- Standardized category and location fields  
- Implemented verification status logic:
  - **Needs Fix** – missing required data  
  - **Ready for Verification** – complete but not verified  
  - **Verified** – verified listings  

---

## 📊 Visualizations
1. Category-wise distribution of listings  
2. Verification status breakdown  
3. City-wise listing analysis  
4. Missing data overview  

---

## 🔍 Key Insights
- Many listings require fixes or verification  
- Urban cities have higher service density  
- Contact details are the most commonly missing fields  
- Cleaned data improves usability and decision-making
